# ZoneEffectAttributeSafety

## ZoneEffectAttributeSafety 1.0.0

### English

Server-side compatibility addon for Dungeons and Combat 1.2.4. It checks that an entity has the required attributes before supported effects apply or remove their bonuses. When an attribute is missing, the adjustment is skipped. Supported effects continue to work normally on entities with the required attributes.

Install this addon on the Forge 1.20.1 server with Java 17, Forge 47.4.23 and Dungeons and Combat 1.2.4. Keep Dungeons and Combat and its dependencies installed as usual. Restart the server to load the addon. Players need no additional client JAR for this addon.

### Español

Complemento de compatibilidad para el servidor de Dungeons and Combat 1.2.4. Comprueba que la entidad tenga los atributos necesarios antes de que los efectos compatibles apliquen o retiren sus bonos. Si falta un atributo, se omite ese ajuste. Los efectos compatibles conservan su comportamiento cuando la entidad tiene los atributos requeridos.

Instala el complemento en el servidor de Minecraft 1.20.1 con Java 17, Forge 47.4.23 y Dungeons and Combat 1.2.4. Conserva el mod original y sus dependencias. Reinicia el servidor para cargar el complemento. Los jugadores pueden conservar sus archivos de cliente.
